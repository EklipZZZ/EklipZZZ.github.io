## 一、复现原则

E2O 采用严格的 training-free 推理：

- 不在水下数据上训练、微调或更新参数；
- 使用官方 OpenCLIP LAION-2B 权重和 DepthAnything-V2；
- MLLM 只读取作者提供的离线 JSON 描述，不直接调用 GPT-4o API；
- 源代码放在 WSL Linux 文件系统，数据和运行结果放在 D 盘；
- 每次正式实验都记录代码提交、环境、权重、数据、配置、硬件和结果。

use_mllm 只是加载缓存 JSON，不会调用 GPT-4o API。

## 十一、MMSegmentation 与 Aqua

Aqua mask 的背景值是 65535，而 MMSegmentation IoU 默认 ignore_index=255。这是评估语义审计点。

由于 B/16 的 Aqua 结果为 17.82，与论文 17.81 一致，当前主复现保留发布代码行为即可，不必优先做双评分。以后如需发布修正版评估，再复制 mask 做 65535 -> 255 的 corrected metric，不能覆盖原始标注。

## 十三、本次消融实测结果

本次实验为 **B/16、released normalization、四个数据集全量评估**。12 个新运行目录均生成 results.txt，未发现 Traceback、OOM 或 ERROR 标记；D 条件沿用已有正式 B/16 基线。

### 2. 平均指标

| 条件 | aAcc | mIoU | mAcc |
|---|---:|---:|---:|
| A：GMG + ImageNet prompt + no MLLM | 53.77 | 32.56 | 48.27 |
| B：GMG + underwater prompt + no MLLM | 57.11 | 35.84 | 53.70 |
| C：GMG + ImageNet prompt + GPT-4o JSON | 60.07 | 38.02 | 54.23 |
| D：GMG + underwater prompt + GPT-4o JSON | 62.01 | 39.78 | 56.99 |

### 3. 直接差值

- 水下 prompt 在无 MLLM 条件下使平均 mIoU 提升 **3.28**（32.56 -> 35.84）。
- MLLM 在 ImageNet prompt 条件下使平均 mIoU 提升 **5.46**（32.56 -> 38.02）。
- MLLM 在水下 prompt 条件下仍提升 **3.94**（35.84 -> 39.78）。
- 水下 prompt 在 MLLM 条件下再提升 **1.76**（38.02 -> 39.78）。
- 两个文本因素同时打开，相比 A 提升 **7.22 mIoU**（32.56 -> 39.78）。

### 4. 结果解释边界

这组结果支持：离线 MLLM 的平均贡献大于水下 prompt，二者均有正向作用；但二者叠加并非简单相加，存在数据集依赖和交互效应。D 条件与已有 B/16 正式结果一致，说明消融运行没有改变主推理链路。

这不是论文 Table 3 的完整复现：本次没有关闭 GMG，且平均值只覆盖四个数据集，不包含 AquaOV255 和 USIS16K。因此可以作为文本分支诊断和后续 idea 选择依据，不能直接写成论文的六数据集完整组件消融表。
