# RSVP：Regional Semantics + Visual Prototypes

原论文：[Refining Open-Vocabulary Semantic Segmentation via Regional Semantics and Visual Prototypes](https://arxiv.org/abs/2610.30623)（2026）。

> **简称说明**：RSVP 是我的 Obsidian 个人简称，来自 **R**egional **S**emantics + **V**isual **P**rototypes。它不是论文作者对整套模型使用的正式缩写。原文模块名是 Regional Semantic Preservation Module、Visual Feature Memory Module。

## 1. 作者针对的两个问题

1. **空间特征问题**：CLIP 的图像编码器主要为图像级图文对齐训练，最后的全局注意力会混合远处 patch，不适合直接给每个像素确定类别。
2. **模态差异问题**：即使得到密集视觉特征，它与类别文本嵌入之间仍有 modality gap。同一个类在实际图像中的外观多样，单纯靠类别文本原型容易误分类。

对应方案：
- **RSP（区域语义保留）**：用 CLIP value 特征构造更适合局部空间聚合的注意力。
- **VFM（视觉特征记忆）**：用无标签图像中高置信的类别像素建立视觉原型，与文本预测融合。
- **Self-training**：另外提供利用伪标签优化分割特征提取器的分支。

## 2. RSP：CLIP 最后一层 Attention 改为 Value–Value

原始 CLIP 的最后注意力使用 query-key 相似度决定加权的 value，图像级训练驱使模型关注全图语义。

作者修改最后一个注意力层，改用 **value 和 value 的空间相似度**计算注意力，并继续聚合 value：

$$
A_{ij}=\operatorname{softmax}_j\left(\frac{v_i^\top v_j}{C}\right),\qquad
\tilde v_i=\sum_j A_{ij}v_j.
$$

这是把论文的 V–V Attention 公式展开成位置索引形式，便于理解“同一语义区域的特征互相强化”。$C$ 为注意力缩放项。

注意它和其他方法的区别：
- [E2O-整理版](/lun-wen-bi-ji/e2o/) 的 GMG 使用**外部几何特征的空间相关性**来引导 CLIP 特征；
- [ProxyCLIP](/lun-wen-bi-ji/proxyclip/) 主要借助 DINO 等 VFM 重构 CLIP 空间对应；
- RSVP 的 RSP **直接从 CLIP 自己的 value 特征构造关系**，不必为这个组件引入外部 DINO。

优势是改动集中、无需重新训练 CLIP；风险是 value 视觉相似不必然代表同一语义实体，相邻近似纹理也可能误传播。

## 3. VFM：给每个类别建立视觉记忆

为什么还需要这一模块？RSP 主要改善空间一致性，并没有从根本上解决**文本原型与目标域视觉外观不对齐**的问题。

### 3.1 构建视觉原型

作者先对**目标无标注图像集合**运行 MaskCLIP，取得每个空间位置的 dense visual feature 和文本类别概率。

对每个类别 $c$：
1. 按类别预测置信度选 **Top-K** 个像素特征；
2. 对选出的特征求均值得到 $F_c^{pixel}$；
3. 对类别原型归一化，构成 Visual Feature Memory；
4. 预测新像素时，除了视觉—文本余弦相似度，再计算视觉—视觉原型相似度。

简化表达：

$$
F_c^{pixel}=\frac1K\sum_{k=1}^K f_{c,k},\qquad
P(F)=C_t(F)+\lambda C_p(F).
$$

其中 $C_t$ 是文本嵌入的预测分支，$C_p$ 是类别视觉原型预测分支，$\lambda$ 为视觉分支残差融合权重。

**关键设定**：视觉原型来自目标数据集的无标签图像集合，而不是每次只看一张待测图像。这是**transductive / target-set-aware** 的适配方式。它不使用人工 GT，不等于对测试数据分布毫无先验。

### 3.2 Top-K 的正反两面

- 选高置信位置可减少普通噪声，获得更稳定的目标域类别视觉外观。
- **高置信也可能系统性误判**。如果水下区域的 fish 经常被高置信认成 coral，类别视觉记忆就会污染，融合反而扩大错误。
- 因此真正值得审查的不是 Top-K 本身，而是**锚点正确率、类别覆盖率、错误类别传播**。

与 [TPA](/lun-wen-bi-ji/tpa/) 的共同点是高置信视觉原型；不同点在具体筛选、原型构造和预测融合机制。PTC 则把视觉证据注入当前图的文本类别原型，切入位置不同。

## 4. 最容易混淆：Annotation-Free ≠ Training-Free

论文 Section 2.4 还有一个 **Self-training** 分支：用前述融合预测产生伪标签，再训练额外的语义分割特征提取器，配合 EMA 平滑参数。实验采用 ImageNet 预训练的 DeepLabv2-ResNet101 作为相应的目标分割网络。

| 路线 | 是否更新模型参数 | 是否需要人工像素 GT |
|---|---|---|
| RSP + VFM 直接预测 | **否**（构建非参数化视觉记忆） | 否 |
| RSP + VFM + 伪标签 Self-training | **是** | 否 |

所以论文完整方法应准确描述为 **Annotation-Free（不依赖人工目标像素标注）**，而非笼统全称 Training-Free。与 E2O 做免训练比较时，应该取**未训练额外网络的分支**。

## 5. 实验与消融（原文 Table 4）

论文在 ADE20K、Cityscapes、COCO-Stuff、PASCAL Context、VOC12AUG 五个评测设置上测试，使用 CLIP ViT-B/16 和 ResNet-50 主干。

在 ViT-B/16 上，五数据集平均 mIoU（%）：

| 方案 | 平均 mIoU |
|---|---:|
| MaskCLIP | 22.6 |
| MaskCLIP + RSP（A） | 23.6 |
| MaskCLIP + A + VFM（V） | **26.0** |
| MaskCLIP+ | 31.0 |
| MaskCLIP+ + A | 34.9 |
| MaskCLIP+ + A + V | 35.5 |
| MaskCLIP+ + A + V + 自训练增强（E） | **35.9** |

注意 **26.0 与 35.9 不是同一基础模型只增加一个组件的前后差异**：两者分别处在 MaskCLIP 与 MaskCLIP+ 的不同设置中，后者本来就涉及伪标签训练体系。

从逐项消融看，单独修改最后注意力能带来收益；加入视觉原型带来额外改善；在自训练体系上还可进一步叠加。

## 6. 对 E2O 的价值及风险

相关：[E2O-整理版](/lun-wen-bi-ji/e2o/)、[TPA](/lun-wen-bi-ji/tpa/)、PTC、[ProxyCLIP](/lun-wen-bi-ji/proxyclip/)、[GeoSeC](/lun-wen-bi-ji/geosec/)。

| 组件 | 可能迁移的思想 | 关键待证问题 |
|---|---|---|
| Value–Value Attention | 替换或对照 E2O 的空间关系构造 | 是否保持正确语义边界？ |
| Top-K 类别视觉原型 | 增强图像—文本赋类 | 高置信错误锚点是否污染原型？ |
| 文本分数 + 视觉分数 | 双路语义校准 | 两个分支的错误是否相互强化？ |
| 伪标签自训练 | 提供额外性能上限参考 | **不满足当前 Training-Free 约束** |

建议先做最小实验：冻结 E2O，在独立的无标签适配池建立原型，比较“E2O 原始输出”和“E2O + 视觉原型分数”，记录 **锚点纯度、覆盖率、类别混淆和三 seed mIoU**。进一步单独比较是否使用目标数据集无标签图像建库，避免评测协议混淆。

## 7. 总结

**这篇论文把两个问题拆开解决：CLIP 特征空间不够局部一致，以及文本类原型与真实外观有差距。** RSP 更接近注意力重构，VFM 更接近类别原型适配；自训练是另外的参数优化阶段。对当前水下 OVSS，最值得研究的是**高置信视觉原型是否可信**，而不是简单叠加更多模块。
