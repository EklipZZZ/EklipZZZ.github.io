## 9. 原论文消融实验清单

### 9.1 组件消融（Table 3，ViT-B/16 六数据集平均）

| 设置 | aAcc | mIoU | mAcc |
|---|---:|---:|---:|
| Baseline | 34.30 | 15.31 | 25.86 |
| + GMG | 46.92 | 27.98 | 42.16 |
| + GMG + UW prompt | 49.93 | 30.81 | 46.62 |
| + GMG + UW prompt + CSA | 54.34 | 34.32 | 49.84 |

论文宣称 GMG、UW prompt、CSA 逐步互补。该表是我们下一阶段最优先复现的消融，因为它直接决定后续创新应加在视觉几何分支还是文本语义分支。

### 9.2 超参数消融（Table 4）

- beta：论文默认 1.2；mIoU 34.32。
- gamma：正文称 3.0 最优，但表中 mIoU 在 1.0 时最高（34.44），aAcc 和 mAcc 在 2.0 时最高。
- `wmax`：正文称 0.5 最优，但表中 0.8 的 aAcc/mIoU/mAcc 均更高（54.65/34.62/50.01）。
- tau：0.1、0.2、0.3 在表中四舍五入后并列；发布主配置/当前运行使用 0.5，对应 34.32。

结论：论文正文“beta=1.2, gamma=3.0, wmax=0.5, tau=0.1 为最优”与表格不完全一致。

### 9.3 几何层消融（Figure 6）

- L：`ViT-L-14`
- H：`ViT-H-14`

使用 `ViT-H/14` 会绕过 H 权重映射并造成维度错误。应统一模型标识并在未知值时 fail fast。

### 10.3 相对路径与 shell 管道风险

- 必须从源码根目录运行，否则 `pretrained_ckpt/*.bin` 相对路径失效；
- `python ... | tee log` 若未启用 `set -o pipefail`，Python 失败仍可能表现为 shell exit code 0；
- 本轮已发生过这两类启动失败，均在推理前终止，没有被计入实验结果。

### 10.4 环境未完全锁定

论文、requirements、当前环境存在版本差异。应导出 `conda env export --from-history`、`pip freeze`、GPU/驱动信息，并为正式消融创建不可变环境记录。

- 完成的 B/16：`REPRODUCIBLE`，指标误差可忽略。

- 整体 18 格主表：`PARTIALLY_REPRODUCIBLE`，因为 L/14 尚未完全解释，且 H/14-USIS16K 的论文设置与方法描述不一致。

该判定不包含统计显著性检验。这里比较的是确定性全量 benchmark 指标，不适合把单次 mIoU 差异包装成 p-value。后续自己的方法比较应至少报告多数据集结果、按类差异、必要时 bootstrap 图像/类别置信区间，并避免只选择有利数据集。
