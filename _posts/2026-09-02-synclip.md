# SynCLIP：论文整理版

> [!summary] 一句话概括
> SynCLIP 关注的不是“有没有识别出这个类别”，而是“同一个类别的不同语言表达，是否仍然指向图像中的同一个空间区域”。它通过训练阶段的 SSA 和 SAR，让规范类别词与同义词、定义描述产生更一致的密集空间响应。

## 1. 先确定论文的身份

| 问题 | 结论 |
|---|---|
| 方法范式 | 基于 CLIP 的语言—图像预训练框架 |
| 主要任务 | Open-Vocabulary Dense Perception，包括开放词汇检测、分割等密集感知任务 |
| 核心问题 | 同一类别的不同文本表达会产生不一致的空间定位 |
| 是否 training-free | 不是。SynCLIP 在训练阶段更新学生视觉编码器 |
| 是否 zero-shot | 是评估意义上的 zero-shot：测试时可以评估训练阶段未见过的新类别 |
| 是否只是自监督方法 | 不能把整个 SynCLIP 简化为自监督或无监督方法；它是在 CLIP/DeCLIP 预训练框架上增加空间一致性约束 |
| 推理时是否使用 SSA/SAR | 不使用训练时的教师分支、DINOv2 分支和空间一致性损失；推理主要使用训练后的学生视觉编码器与文本编码器 |

这里最容易混淆的是：

- zero-shot 描述的是测试时能否处理新类别；
- training-free 描述的是目标数据上是否完全不更新参数；
- SynCLIP 属于前者，不属于后者。

因此，SynCLIP 可以作为 E2O 的思想来源，但不能直接作为严格 training-free 主方法。

## 2. 论文究竟要解决什么问题？

### 2.1 从全局图文对齐到局部空间对齐

普通 CLIP 更擅长学习整张图像与整段文本之间的全局相似度：

$$
I \longleftrightarrow t
$$

但开放词汇检测和分割需要更细的对应关系：

$$
\text{图像中的局部 patch 或区域}
\longleftrightarrow
\text{类别文本}
$$

如果文本只换了一种说法，模型仍然应该定位相同的物体，而不是把注意力转移到背景、纹理或其他相关物体上。

### 2.2 同义词造成的 grounding inconsistency

假设类别是 zebra，文本表达可以是：

- zebra；
- striped horse；
- a horse with black-and-white stripes；
- 关于斑马外观的定义描述。

这些表达的语义大体接近，但它们在视觉上突出的部分可能不同。一个表达可能更关注整体轮廓，另一个表达可能更关注条纹，还有一个表达可能错误地关注草地或马匹形状。

> [!evidence] 论文问题
> 语言语义相近，不代表 CLIP 的密集空间响应已经天然一致。对于 dense perception，文本变体之间的空间响应差异会直接影响定位和掩码质量。

> [!inference] 对方法设计的推断
> SynCLIP 的重点不是重新发明 CLIP 的语义空间，而是利用视觉教师、同义词文本和视觉几何信息，给学生视觉编码器增加“空间响应应保持一致”的训练信号。

## 3. SEViC：同义词从哪里来？

### 3.1 SEViC 的作用

SynCLIP 先建立 Synonym-Enriched Visual Corpus（SEViC），把原有视觉类别扩展为多种语言表达，使训练阶段可以观察同一类别的不同文本形式。

当前笔记记录的规模是：

| 项目 | 数量 |
|---|---:|
| 基础类别 | 1,232 |
| 额外元类别 | object、background |
| 总类别数 | 1,234 |
| 图像数 | 118,287 |
| 语义增强表达 | 11,558 |
| 数据基础 | COCO 与 LVIS 类别体系 |

### 3.2 同义词不是 SSA 在推理时生成的

这条边界需要单独记住：

1. SEViC 中的同义词和定义描述，是训练数据准备阶段离线构造的；
2. 论文使用大语言模型生成或扩展候选表达，并进行过滤、检查和整理；
3. SSA 不负责生成同义词，它负责利用这些文本变体构造空间一致性监督；
4. 推理时不需要临时运行 SSA 来生成同义词。

因此，SynCLIP 的逻辑是：

$$
\text{类别}
\rightarrow
\text{多个语言表达}
\rightarrow
\text{训练时构造一致的空间监督}
\rightarrow
\text{得到更稳健的学生视觉编码器}
$$

### 3.3 SEViC 数据准备流程

~~~mermaid
flowchart LR
    C["COCO / LVIS 类别"] --> L["大语言模型生成同义词与定义"]
    L --> F["过滤、去重、语义检查"]
    F --> S["SEViC：每个类别的多种表达"]
    S --> T["训练阶段的文本变体"]
    S --> R["同义词鲁棒性评估"]
~~~

## 4. 记号与 embedding 到底是什么？

### 4.1 主要编码器

| 记号                       | 含义                                    | 训练状态           |
| ------------------------ | ------------------------------------- | -------------- |
| $F_v$                  | 学生视觉编码器                               | 训练时更新          |
| $F_v^*$                | CLIP 视觉编码器的冻结教师副本                     | 冻结             |
| $F_t$                  | 文本编码器                                 | 按论文设置冻结        |
| $F_v^{\mathrm{VFM}}$   | DINOv2 视觉基础模型                         | 冻结             |
| $I$                    | 输入图像                                  | 输入             |
| $X_{\mathrm{dense}}$   | 学生视觉编码器产生的 patch-level dense features | 由 $F_v$ 产生   |
| $X_{\mathrm{dense}}^*$ | 教师视觉编码器产生的 patch-level dense features | 由 $F_v^*$ 产生 |
| $t_{\mathrm{label}}$   | 规范类别词的文本 embedding                    | 由 $F_t$ 产生   |
| $t_{\mathrm{sem}}$     | 同义词或定义描述的文本 embedding                 | 由 $F_t$ 产生   |

这里的 embedding 不是一个神秘的额外数据，而是编码器输出的向量：

- 图像 embedding：视觉编码器把图像转换成向量；
- dense image embedding：保留空间位置的 patch 向量集合；
- 文本 embedding：文本编码器把类别词、同义词或定义转换成向量。

若图像被划分为 $N$ 个 patch，每个 patch 的特征维度为 $d$，则可以写成：

$$
X_{\mathrm{dense}}\in\mathbb{R}^{N\times d},
\qquad
t_{\mathrm{label}},t_{\mathrm{sem}}\in\mathbb{R}^{1\times d}.
$$

### 4.2 CSA 与 dense token

论文使用 CLIP 的自注意力特征得到更适合密集感知的 patch 表达。当前笔记中的记号为：

$$
\mathrm{Attn}_{\mathrm{csa}}
 =
\mathrm{SoftMax}\left(\frac{QQ^{\mathsf T}}{\tau}\right)
 +
\mathrm{SoftMax}\left(\frac{KK^{\mathsf T}}{\tau}\right),
\qquad
\tau=\sqrt{d}.
$$

移除 CLS token 后，剩余 token 对应图像 patch，组成 $X_{\mathrm{dense}}$。所以：

- patch token 是图像被视觉编码器分块后的局部表示；
- global image embedding 是对整张图像的汇总表示；
- dense perception 不能只依赖 global embedding，因为它还需要知道每个局部位置对应什么。

## 5. 总体流程：从文本变体到空间一致性

### 5.1 论文原始方法图

![Pasted image 20260901035251](/assets/images/obsidian/667a266e58c2402932fe98f3d3231ae2.png)

下面的流程图把模块和公式放在同一条链路中：

~~~mermaid
flowchart TD
    I["输入图像 I"] --> SV["学生视觉编码器 F_v"]
    I --> TV["冻结视觉教师 F_v*"]
    I --> DV["冻结 DINOv2 F_v^VFM"]
    SV --> XS["X_dense"]
    TV --> XT["X_dense*"]
    DV --> XD["DINOv2 patch features"]

    P1["规范类别文本"] --> FT["冻结文本编码器 F_t"]
    P2["同义词或定义文本"] --> FT
    FT --> TL["t_label"]
    FT --> TS["t_sem"]

    TL --> AL["A_label = cosine(t_label, X_dense)"]
    XS --> AL
    TS --> AS["A_sem = cosine(t_sem, X_dense*)"]
    XT --> AS

    AS --> TOP["TopK 选择语义 token"]
    TOP --> SPA["DINOv2 空间相似度聚合 A_spa"]
    AS --> AGG["A_agg = alpha A_spa + beta A_sem"]
    SPA --> AGG

    AL --> LOSS["L_semantic+：A_label 对齐 A_agg"]
    AGG --> LOSS
    BASE["L_DeCLIP"] --> TOTAL["L_total"]
    LOSS --> TOTAL
    TOTAL --> UPDATE["只更新学生视觉编码器"]
~~~

这条链的核心关系是：

$$
\text{规范文本}
\xrightarrow{F_t}
t_{\mathrm{label}}
\xrightarrow{\text{与学生 dense feature 相似度}}
A_{\mathrm{label}}
$$

以及：

$$
\text{同义词或定义}
\xrightarrow{F_t}
t_{\mathrm{sem}},
\qquad
\text{冻结教师图像特征}
\xrightarrow{F_v^*}
X_{\mathrm{dense}}^*
\xrightarrow{\text{相似度}}
A_{\mathrm{sem}}.
$$

随后 SAR 把语言相似度与视觉空间几何合并为 $A_{\mathrm{agg}}$，让学生分支学习：

$$
A_{\mathrm{label}}\approx A_{\mathrm{agg}}.
$$

## 6. SSA：让规范词和同义词指向相同位置

### 6.1 两张 attention map

对规范类别文本和学生 dense features 计算：

$$
A_{\mathrm{label}}
 =
\frac{
t_{\mathrm{label}}X_{\mathrm{dense}}^{\mathsf T}
}{
\lVert t_{\mathrm{label}}\rVert
\lVert X_{\mathrm{dense}}\rVert
}.
$$

对同义词或定义文本和冻结教师 dense features 计算：

$$
A_{\mathrm{sem}}
 =
\frac{
t_{\mathrm{sem}}\left(X_{\mathrm{dense}}^*\right)^{\mathsf T}
}{
\lVert t_{\mathrm{sem}}\rVert
\lVert X_{\mathrm{dense}}^*\rVert
}.
$$

如果 $X_{\mathrm{dense}}$ 有 $N$ 个 patch，那么两张 map 都可以看成长度为 $N$ 的空间响应，之后再 reshape 回 patch 网格。

### 6.2 SSA 的监督目标

SSA 的基本目标是最小化两张空间响应图的差异：

$$
L_{\mathrm{semantic}}
 =
\frac{1}{nm}
\sum_{i=1}^{n}
\sum_{j=1}^{m}
\left\|
A_{\mathrm{label}}^{i,j}
-
A_{\mathrm{sem}}^{i,j}
\right\|_2^2.
$$

论文最终使用经过 SAR 修正的 $A_{\mathrm{agg}}$ 作为目标，得到语义增强版本：

$$
L_{\mathrm{semantic+}}
 =
\frac{1}{nm}
\sum_{i=1}^{n}
\sum_{j=1}^{m}
\left\|
A_{\mathrm{label}}^{i,j}
-
A_{\mathrm{agg}}^{i,j}
\right\|_2^2.
$$

### 6.3 这一步到底更新谁？

训练时：

1. $A_{\mathrm{label}}$ 依赖学生视觉编码器 $F_v$，所以它能接收梯度；
2. $A_{\mathrm{sem}}$ 依赖冻结教师 $F_v^*$和冻结文本编码器 $F_t$，作为相对稳定的目标；
3. $L_{\mathrm{semantic+}}$推动学生对规范类别词的响应，靠近同义词表达所对应的目标区域；
4. 最终被更新的是学生视觉编码器，而不是临时修改 CLIP 文本语义空间。

因此，SSA 的本质可以概括为：

$$
\text{不同文本表达}
\rightarrow
\text{不同空间响应}
\rightarrow
\text{用教师目标约束学生}
\rightarrow
\text{空间响应趋于一致}.
$$

## 7. SAR：用 DINOv2 的视觉几何细化目标区域

SSA 只利用文本—图像相似度构造 $A_{\mathrm{sem}}$。当同义词响应本身较粗糙，或者只选一个语义 token 时，目标 map 可能仍然不完整。SAR 用 DINOv2 的局部视觉相似性补充空间结构。

### 7.1 选择语义相关 token

先从 $A_{\mathrm{sem}}$ 中选出响应最高的 $k$ 个 token：

$$
K=\operatorname{TopK}\left(A_{\mathrm{sem}},k\right).
$$

论文记录的较优设置为：

$$
k=7.
$$

这里的 $K$ 是 patch/token 的位置集合，不是类别集合。

### 7.2 用 DINOv2 计算局部空间相似度

设 DINOv2 在位置 $i$ 和 $j$ 的 patch features 分别为 $x_i^{\mathrm{VFM}}$ 与 $x_j^{\mathrm{VFM}}$，则空间相似度为：

$$
s_{i,j}
 =
\frac{
x_i^{\mathrm{VFM}}\cdot x_j^{\mathrm{VFM}}
}{
\max\left(
\lVert x_i^{\mathrm{VFM}}\rVert
\lVert x_j^{\mathrm{VFM}}\rVert,
\varepsilon
\right)
}.
$$

对每个被选中的语义 token $i$，可以得到一张 DINOv2 空间相似度图 $S_i$。再对 $K$ 中的 token 求平均：

$$
A_{\mathrm{spa}}
 =
\frac{1}{k}
\sum_{i\in K}S_i.
$$

### 7.3 语义和空间两种信息融合

最终的聚合目标为：

$$
A_{\mathrm{agg}}
 =
\alpha A_{\mathrm{spa}}
 +
\beta A_{\mathrm{sem}},
$$

默认设置为：

$$
\alpha=\beta=0.5.
$$

可以这样理解：

- $A_{\mathrm{sem}}$：哪些位置和文本表达语义上相似；
- $A_{\mathrm{spa}}$：哪些位置在视觉特征空间中属于同一片连续或相似区域；
- $A_{\mathrm{agg}}$：语义证据与视觉几何证据融合后的监督目标。

### 7.4 为什么 $k$ 不能无限增大？

如果只选很少的 token，可能只覆盖物体最显著的局部；如果选太多，低响应 token 可能来自背景或其他物体。论文记录的趋势是：

| $k$ | OV-COCO 结果 |
|---:|---:|
| 1 | 42.5 |
| 7 | 43.6 |
| 10 | 42.2 |
| 20 | 41.5 |

这说明 SAR 不是“选得越多越好”，而是在语义可靠性和空间覆盖范围之间寻找平衡。

## 8. 总损失与训练边界

SynCLIP 将基础 DeCLIP 目标和语义空间一致性目标结合：

$$
L_{\mathrm{total}}
 =
L_{\mathrm{DeCLIP}}
 +
\lambda_{\mathrm{sem}}L_{\mathrm{semantic+}},
$$

其中当前笔记记录：

$$
\lambda_{\mathrm{sem}}=0.05.
$$

训练阶段可以画成：

$$
\begin{aligned}
&\text{图像 }I
\rightarrow
\{F_v(I),F_v^*(I),F_v^{\mathrm{VFM}}(I)\},\\
&\text{规范词、同义词、定义}
\rightarrow
\{t_{\mathrm{label}},t_{\mathrm{sem}}\},\\
&\{t_{\mathrm{label}},X_{\mathrm{dense}}\}
\rightarrow A_{\mathrm{label}},\\
&\{t_{\mathrm{sem}},X_{\mathrm{dense}}^*\}
\rightarrow A_{\mathrm{sem}},\\
&\{A_{\mathrm{sem}},F_v^{\mathrm{VFM}}(I)\}
\rightarrow A_{\mathrm{agg}},\\
&\{A_{\mathrm{label}},A_{\mathrm{agg}}\}
\rightarrow L_{\mathrm{semantic+}},\\
&L_{\mathrm{DeCLIP}}+\lambda_{\mathrm{sem}}L_{\mathrm{semantic+}}
\rightarrow \text{更新 }F_v.
\end{aligned}
$$

冻结分支的作用不是“没有用”，而是提供稳定参照：

| 分支 | 作用 | 是否更新 |
|---|---|---|
| 学生 $F_v$ | 学习更稳定的 dense visual representation | 是 |
| 教师 $F_v^*$ | 提供 CLIP 视觉语义空间中的相对稳定目标 | 否 |
| 文本编码器 $F_t$ | 把规范词、同义词和定义映射到文本空间 | 按当前设置冻结 |
| DINOv2 | 提供局部视觉几何和空间相似性 | 否 |

## 9. 训练时使用什么，推理时使用什么？

### 9.1 训练阶段

训练阶段有完整的辅助链：

$$
\text{SEViC 文本变体}
+\text{学生/教师视觉分支}
+\text{DINOv2}
\rightarrow
\text{SSA/SAR 监督}
\rightarrow
\text{更新学生 }F_v.
$$

### 9.2 推理阶段

推理阶段使用训练完成的学生编码器和文本编码器：

$$
I
\xrightarrow{F_v}
X_{\mathrm{dense}}
,\qquad
p_c
\xrightarrow{F_t}
t_c,
\qquad
\operatorname{score}(p,c)
 =
\cos(x_p,t_c).
$$

训练时的 $F_v^*$、DINOv2、TopK、$A_{\mathrm{spa}}$ 和一致性损失不再作为主推理链的一部分。

这也是 SynCLIP 能够改善推理的原因：它不是在每张测试图像上重新优化，而是先把“同义词应当空间一致”的能力写进学生视觉编码器。

## 11. 与其他工作放在同一坐标系中

| 工作 | 是否 training-free | 主要输入 | 主要解决点 | 对 E2O 的启发 |
|---|---|---|---|---|
| TextRegion | 是 | SAM2 区域 mask、region token、CLIP | 把区域级视觉信息接入开放词汇分割 | 重点检查区域 mask 质量，再做区域—文本匹配 |
| WaveDN | 是 | 无标签测试样本、DWT embedding | 利用测试分布修正 embedding | 关注水下域分布，不更新参数 |
| FDAM | 否 | 训练数据、注意力和频域特征 | 学习 dense prediction 的特征增强 | 可借鉴频域/注意力分析，但不直接满足严格 training-free |
| SynCLIP | 否 | 同义词文本、教师视觉特征、DINOv2 | 让语言变体产生一致的空间响应 | 改写成推理时 prompt consensus 或 region-score consensus |

四篇工作的关注层级不同：

$$
\text{TextRegion：区域质量}
\rightarrow
\text{WaveDN：域分布}
\rightarrow
\text{SynCLIP：语言变体一致性}
\rightarrow
\text{FDAM：特征/注意力增强}.
$$

这不是说它们可以直接串联，而是帮助定位 E2O 的误差来源：

1. SAM2 是否生成了正确的候选区域；
2. 水下图像的视觉 embedding 是否发生了域偏移；
3. 文本提示词变化是否改变了区域排序；
4. CLIP patch 特征是否保留了足够的局部判别信息。

## 12. 对 E2O training-free 研究的可迁移版本

### 12.1 不能直接搬运的部分

SynCLIP 的 SSA/SAR 依赖训练阶段的学生视觉编码器更新，因此不能原封不动地放入 E2O 的严格 training-free 主链。

可以借鉴的是它的研究思想：

> 同一个类别的多种文本表达，应该对同一个候选区域给出相互支持的证据。

### 12.2 推理时 prompt consensus

对类别 $c$ 构造多个提示词：

$$
P_c=
\left\{
p_1(c),p_2(c),\ldots,p_L(c)
\right\}.
$$

文本编码器得到：

$$
t_{c,l}=F_t\left(p_l(c)\right).
$$

对于 TextRegion 产生的区域 embedding $y_r$，把单一文本相似度改成多提示词集成：

$$
s_{r,c}^{\mathrm{ens}}
 =
\frac{1}{L}
\sum_{l=1}^{L}
\cos\left(y_r,t_{c,l}\right).
$$

如果不同提示词的可靠性不同，也可以使用归一化权重：

$$
s_{r,c}^{\mathrm{w}}
 =
\sum_{l=1}^{L}
w_l\cos\left(y_r,t_{c,l}\right),
\qquad
\sum_{l=1}^{L}w_l=1.
$$

也可以在 patch/区域响应层做共识：

$$
A_c^{\mathrm{ens}}(p)
 =
\frac{1}{L}
\sum_{l=1}^{L}
A_{c,l}(p).
$$

这里的平均不是训练，也不改变任何模型参数；它只是推理时的提示词集成和后处理。

### 12.3 水下提示词的分组

不要把所有句子无差别平均，可以先按功能分组：

| 提示词组 | 作用 | 例子方向 |
|---|---|---|
| 类别词 | 保留基础语义锚点 | object class |
| 同义/近义词 | 检验语言变体稳定性 | alternative name |
| 外观属性 | 强调颜色、纹理、形状 | visible appearance |
| 水下场景词 | 提供水下成像语境 | underwater object / scene |

> [!hypothesis] 面向 E2O 的候选假设
> 对水下物体来说，类别词、可见外观属性和水下语境可能提供互补信息；但场景词也可能过度强调水体、光照或背景，因此不应默认与类别词等权。

### 12.4 最小验证实验

固定 E2O 的 SAM2 masks、CLIP backbone、后处理和数据子集，只改变文本输入：

| 组别 | 文本设置 |
|---|---|
| A | 单一类别 prompt |
| B | 3–5 个同义/近义 prompt 的平均 |
| C | 类别词 + 外观属性 + 水下语境的分组加权 ensemble |

统一报告：

- mIoU；
- mAcc；
- aAcc；
- 区域级类别排序；
- 典型图像上的响应图或 mask 可视化；
- 每张图的候选区域数量和推理时间。

最小研究问题可以写成：

$$
\text{prompt consensus}
\stackrel{?}{\Longrightarrow}
\text{更稳定的区域分类与分割结果}.
$$

### 12.5 预期失败条件

| 失败条件 | 可能表现 |
|---|---|
| 近义词并不真正等价 | 平均后语义边界变模糊 |
| 水下场景 prompt 过强 | 背景水体得分升高，前景被淹没 |
| 提示词数量过多 | 引入低质量表达，区域排序下降 |
| SAM2 漏掉目标 | 文本共识无法恢复不存在的候选区域 |
| 所有 prompt 都受同一域偏移影响 | 共识只会稳定地产生错误 |
| 类别过于细粒度 | 通用 CLIP 语义无法区分相近物种或装备 |

## 13. 当前阅读结论

1. SynCLIP 的真正贡献点是 dense spatial grounding 的语言变体一致性，不是简单增加同义词数量。
2. SEViC 负责提供多种文本表达；SSA 负责让规范词和语义变体的空间响应接近；SAR 用 DINOv2 的视觉几何补充目标区域。
3. 教师分支和 DINOv2 都是训练期参照，最终要被学生视觉编码器吸收；这正是它与 training-free 方法的根本区别。
4. 消融结果显示，SAR 的空间信息比 SSA 单独的文本对齐更有增益，二者结合最好。
5. 对 E2O 最适合的迁移不是训练 SynCLIP，而是把“语言变体空间一致性”改写为推理时的多提示词共识。

### 13.1 给 E2O 的直接研究线索

在 TextRegion 的区域级相似度计算中，先保留原始单 prompt 作为基线，再加入：

$$
\text{区域 mask}
\rightarrow
\text{region embedding}
\rightarrow
\text{多提示词相似度}
\rightarrow
\text{共识排序}
\rightarrow
\text{mask 分类与合并}.
$$

这样可以把 SynCLIP 的核心思想压缩成一个严格 training-free、可单独消融的模块：

$$
\boxed{
\text{Synonym-Coherent Region Scoring}
}
$$

它首先回答一个清晰问题：在候选区域和视觉 backbone 固定的情况下，多种水下类别表达能否降低区域分类的不稳定性？

## 14. 术语速查

| 术语 | 在本文中的准确含义 |
|---|---|
| global image feature | 汇总整张图像的向量，缺少明确的 patch 空间位置 |
| dense feature | 保留 patch 空间位置的局部视觉向量集合 |
| synonym | 同一类别的替代表达，不等于 SSA 临时生成的文本 |
| $A_{\mathrm{label}}$ | 规范类别文本与学生 dense features 的相似度图 |
| $A_{\mathrm{sem}}$ | 语义变体文本与冻结教师 dense features 的相似度图 |
| $A_{\mathrm{spa}}$ | 基于 DINOv2 局部视觉相似度聚合的空间图 |
| $A_{\mathrm{agg}}$ | $A_{\mathrm{sem}}$ 与 $A_{\mathrm{spa}}$ 的融合目标 |
| SSA | 规范类别词与语义变体之间的空间响应对齐 |
| SAR | 使用视觉几何信息对语义目标区域进行细化 |
| zero-shot | 测试类别可以与训练类别不同 |
| training-free | 目标数据上不更新模型参数 |
